# Brand Guidelines — SOLOMON.AI

## Overview
This document summarizes the brand identity for SOLOMON.AI: logo usage, color palette, typography, tone of voice, and bilingual layout guidance.

## Logo
- Primary logo file: assets/logo.svg
- Use the full-color logo on white or very light backgrounds.
- Maintain clear space equal to the height of the logo "S" around the mark.
- Do not distort or recolor the logo; use monochrome white for dark backgrounds if needed.

## Colors
- Primary: #1A5FC9 (deep blue)
- Accent: #66B5FF (sky blue)
- Background: #F6F9FF (soft off-white)
- Panel / Card: #FFFFFF (white)
- Text: #1B2636 (soft black)
- Muted: #58677A (muted gray-blue)

## Typography
- Headings: strong, condensed weight (use system UI or bold sans)
- Body: clean, readable sans-serif (Arial, Helvetica, system fonts)
- Arabic: use a clear geometric Naskh or simplified Kufi where available; ensure font supports Arabic script properly.

## Tone of Voice
- Professional, clear, and compassionate.
- Use direct, active language for procedures and guidance.
- For patient-facing materials, use plain-language and avoid jargon.

## Bilingual Guidance
- Keep English and Arabic texts equivalent in meaning, not literal word-for-word.
- Present Arabic right-to-left (RTL) blocks using dir="rtl" or CSS direction when rendering pages.
- Avoid long, dense paragraphs in either language on public-facing pages.

## Assets
- Logo: assets/logo.svg
- Styles: styles.css
- Use SVG for logo to preserve quality.
